# Maintainable Code Craft

一个以**整体工程判断**为核心的轻量代码质量 Skill。它强调理解系统、明确职责、自然实现和适度验证，而不是要求模型遵循固定的开发流程。

## 核心理念

优秀的工程方案并不等于修改最少、代码最短或检查最多，而是让解决方案的范围与结构真正适合问题。

- **整体理解**：结合真实调用链、数据、状态、依赖及最终用户体验判断问题。面对宽泛目标，先思考理想的系统状态，避免局部修修补补。
- **合理归属**：让规则与事实由恰当的模块负责，移除失去用途的机制和不必要的抽象；如果问题跨越模块，就允许完整的跨模块重构。
- **自然编码**：采用符合语言与项目习惯的直接实现、清晰接口和解释重要原因的注释。
- **可靠而不过度**：关注行为契约、异常、金融单位、持久化与授权等重要边界；通过真正有意义的证据验证结果，而非机械堆叠检查。
- **关注最终效果**：以正确性、可维护性、性能与整体一致性评价工作，不以行数、文件数量或测试数量作为目标。

这个 Skill 是**工程判断的参考**，不是流程规范。局部问题可以只修改几行，架构问题也可以合理改造多个模块。项目规则、业务约束和用户授权始终优先。

## 安装与使用

将仓库安装到编码助手的 Skill 目录，并保持 `SKILL.md` 位于 Skill 根目录。可以隐式使用或显式调用，例如：

```text
使用 maintainable-code-craft 从系统整体审查并提出最合理的完整方案。
```

```text
在保留既有功能的基础上，重构这个子系统的职责与实现，使其更自然、更易维护。
```

不依赖固定步骤、专门的流程文档，也不强制调用其他 Skill。
